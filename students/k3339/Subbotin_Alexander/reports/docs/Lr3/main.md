# Лабораторная работа 3. Парсинг данных и фоновые задачи

## Цель

Разработать систему сбора данных с использованием парсеров и фоновой очереди задач. Контейнеризировать приложение с помощью Docker.

---

## Задание

- Написать парсер (веб-скрапинг или работа с API) для сбора данных
- Настроить очередь задач на **Celery** + **Redis** (или RabbitMQ)
- Запустить всё в **Docker Compose**: приложение, воркер, брокер, БД
- Реализовать хранение собранных данных в PostgreSQL

---

## Стек технологий

| Компонент | Технология |
|---|---|
| Парсинг | `httpx` / `BeautifulSoup` / `playwright` |
| Очередь задач | Celery |
| Брокер | Redis / RabbitMQ |
| База данных | PostgreSQL |
| Контейнеризация | Docker + Docker Compose |
